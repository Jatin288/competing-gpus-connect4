Project Architecture & Design Walkthrough

ðŸ”´ Competitor 1: GPU Minimax

Uses a parallel depth tree search evaluating all 7 candidate column drops simultaneously in separate CUDA thread blocks.

  • Block Hierarchy: 7 blocks (one per candidate column), each launching 256 threads.
  • Tree Search: Threads evaluate prospective 2-ply and 3-ply combinations of opponent replies.
  • Shared Memory Reduction: Block-wide parallel reduction minimizes global memory round-trips to score candidate heuristic utility.

ðŸŸ¡ Competitor 2: GPU Monte Carlo (MCTS)

Uses massive thread parallelism to simulate stochastic games forward in time.

  • Parallel Rollouts: Launches 1,024 independent random rollouts per legal column.
  • Linear Congruential Generator: Ultra-fast register-based PRNG computes thousands of random turns without CPU overhead.
  • Atomic Accumulation: Atomic add tallies wins/losses directly in shared memory to select the column with the highest win probability.

Addresses the dual-GPU tournament requirement with seamless fallback for single-GPU environments.

  • Dual Physical GPUs: Assigns separate device contexts via cudaSetDevice(0) and cudaSetDevice(1).
  • Coursera Lab Fallback: Employs cooperative lock-file IPC (game_turn.lock and board_state.json) allowing two independent GPU processes to take turns without race conditions.
